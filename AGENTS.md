# Agent rules for twake-phone

- Decisions: each package keeps its own `docs/decisions.md` (`apps/*/docs/decisions.md`, `packages/*/docs/decisions.md`), mandatory, none at the repo root. Search the log of the package you change before asking a question or proposing a change; record every decision in the log of the package it touches (the main one when it touches several, the others in its Scope line), in the commit that applies it (skill `twake-decisions`).
